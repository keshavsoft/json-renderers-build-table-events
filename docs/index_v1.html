Instruction-Driven Event Layer

json-renderers-build-table-events

Decoupled, instruction-driven event orchestration for table components. Pure declarative DOM traversal without brittle selectors or hardcoded ID dependencies.

GitHub Repository → Explore Interactive Demo ↓
Philosophy 01
Decoupled Responsibilities

Rendering owns the DOM structure. Events own the interactivity. Conflating them destroys typing focus during live searches.

Philosophy 02
Declarative Traversal

Element lookups are defined in serializable instructions.json recipes executed by dom-primitive-engine.

Philosophy 03
Self-Contained Actions

Zero cross-linking or premature abstractions. Each domain action (search, row select, save) owns its complete cycle.

How to Consume in Your Application
import { hookTableEvents } from "https://keshavsoft.github.io/json-renderers-build-table-events/dist/v1/min.js";

hookTableEvents({
    container: "demo-table-wrapper",
    dataset: initialRecords,
    columns: columnsDefinition,
    renderTable: (updatedData) => {
        // Only repaints inner <tbody> or table-content-container!
        // Search input outside is untouched and keeps keyboard focus.
        renderInnerTable(updatedData);
    },
    onSearch: (query, filteredData) => console.log("Searching:", query),
    onRowClick: (record, rowIndex) => console.log("Selected row:", record),
    onRowAction: (action, record, rowIndex) => console.log("Action:", action, record),
    onSave: (newRecord, dataset) => console.log("Saved new item:", newRecord)
});
