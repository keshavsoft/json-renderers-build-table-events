Developer Guide

How to Use

Complete step-by-step instructions for installing, configuring, and wiring table events in your application.

1. Installation

Install via npm as a project dependency:

npm install json-renderers-build-table-events

Or include it directly in the browser via CDN script tag:

<script type="module" src="https://keshavsoft.github.io/json-renderers-build-table-events/dist/v1/min.js"></script>

2. HTML Markup Setup

Ensure your table container has a search input and table structure with standard data attributes: 

<div id="my-table-wrapper">
    <!-- Search Bar (outside table rows to preserve focus) -->
    <input type="search" id="tableSearch" placeholder="Search...">
    <span id="search-feedback"></span>

    <!-- Inner Table Container -->
    <div id="table-content-container">
        <table class="table">
            <tbody id="table-body">
                <!-- Rows rendered here -->
            </tbody>
            <tfoot>
                <tr>
                    <td><input name="itemName" placeholder="Item Name"></td>
                    <td><input name="category" placeholder="Category"></td>
                    <td><input name="baseUnit" placeholder="Base Unit"></td>
                    <td><button data-role="table-save">Save</button></td>
                </tr>
            </tfoot>
        </table>
    </div>
</div>

3. JavaScript Wiring

Call hookTableEvents with your dataset and event handlers:

import { hookTableEvents } from "json-renderers-build-table-events";

const dataset = [
    { itemName: "0.09/30mm High Tensile Bolt", category: "Fasteners", baseUnit: "kgs" },
    { itemName: "0.11-25 Galvanized Wire Coil", category: "Raw Materials", baseUnit: "kgs" }
];

const columns = [
    { columnName: "itemName" },
    { columnName: "category" },
    { columnName: "baseUnit" }
];

hookTableEvents({
    container: document.getElementById("my-table-wrapper"),
    dataset: dataset,
    columns: columns,

    // Called when search filters rows - update ONLY the inner table / tbody
    renderTable: (filteredRecords) => {
        const tbody = document.getElementById("table-body");
        tbody.innerHTML = filteredRecords.map((r, i) => `
            <tr>
                <td>${r.itemName}</td>
                <td>${r.category}</td>
                <td>${r.baseUnit}</td>
                <td><button data-action="show" class="btn btn-sm">Show</button></td>
            </tr>
        `).join("");
    },

    // Triggered as user types
    onSearch: (query, filteredRecords) => {
        console.log(`Search: "${query}", Matches: ${filteredRecords.length}`);
    },

    // Triggered on row click
    onRowClick: (record, rowIndex) => {
        console.log("Selected row:", record);
    },

    // Triggered on button click with data-action attribute
    onRowAction: (action, record, rowIndex) => {
        console.log(`Action: ${action} on row:`, record);
    },

    // Triggered on footer save button click
    onSave: (newRecord, updatedDataset) => {
        console.log("Saved new record:", newRecord);
    }
});

4. Options & Callbacks Reference

Option Type Description
container HTMLElement | string Parent container wrapping both search bar and table.
dataset Array<Object> Initial array of data records.
columns Array<Object> Column configuration array specifying column names.
renderTable Function(filteredRecords) Callback function to repaint inner table body with filtered data.
onSearch Function(query, filteredRecords) Fired on search input events; receives search query and filtered records.
onRowClick Function(record, rowIndex) Fired when any table body row is clicked.
onRowAction Function(action, record, rowIndex) Fired when an action button with data-action is clicked.
onSave Function(newRecord, updatedDataset) Fired when footer save button is clicked with values collected from input fields.
