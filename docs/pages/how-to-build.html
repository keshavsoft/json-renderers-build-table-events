How to Build

Learn how to clone the repository, install dependencies, and build the distribution bundles locally.

1. Prerequisites

Before building, make sure you have the following installed on your machine:

  • Node.js: v16.x or later (v18+ recommended)
  • npm: v8.x or later
  • Git: For version control and cloning

2. Clone & Install Dependencies

Clone the repository from GitHub and install all required development and runtime dependencies:

# Clone repository
git clone https://github.com/keshavsoft/json-renderers-build-table-events.git

# Enter project directory
cd json-renderers-build-table-events

# Install dependencies
npm install

3. Execute the Build Script

The build script uses @keshavsoft/build-cli to bundle and minify source files into the distribution directory: 

npm run build

This command compiles the modular source code from src/ into:

  • docs/dist/v1/min.js (production-ready ES module and global bundle)
  • docs/dist/min.js (root distribution entry point)

4. Testing & Local Preview

To test your changes and view documentation locally, you can serve the docs/ directory using any static file server: 

# Using npx serve
npx serve docs

# Or using Python 3
python -m http.server 8080 --directory docs
